# ExpenseBud 💸

ExpenseBud is a student-focused web application designed to help track expenses, set budgets, and build financial discipline.  
Inspired by the **Njilo Mentorship Program**, which encouraged students to prepare for the future and create better visions of themselves.

---

## 🚨 Problem Identified
Many students struggle with:
- Not knowing how to track expenses
- Difficulty differentiating between needs and wants
- Peer pressure to overspend on outings and social events
- Frequent small purchases that drain allowances

---

## ✅ Solution
ExpenseBud helps students:
- Track income and expenses in real time
- Set monthly budgets per category (e.g., food, transport, entertainment)
- Visualize spending with charts and summaries
- Build financial literacy and smart spending habits

---

## 🛠 Tech Stack
- **Frontend:** Vite + JavaScript
- **Backend:** Supabase (authentication, database, RLS policies)
- **Deployment:** Vercel
- **UI Components:** Custom modals, charts, and lists

---

## 🔐 Features
- Secure authentication (sign up, sign in, password reset)
- Row-Level Security (RLS) ensures each user only sees their own data
- Add, edit, and delete categories and transactions
- Spending breakdown with donut charts
- Budget tracking per category
- Light/Dark theme toggle

---
